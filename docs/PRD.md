# 个人展示网站 · 产品需求文档（简化版）

| 项目 | 内容 |
| --- | --- |
| 用途 | AI 课程作业 / 个人作品展示 |
| 版本 | v3.0（简化版） |
| 形态 | 响应式网站 + 简易管理后台 |
| 技术 | Next.js + TypeScript + 本地 JSON 存储 |
| 说明 | 详细版方案见 `docs/PRD-detailed.md`，本版只保留作业需要的能力 |

---

## 1. 目标

做一个深色星空风格的个人网站，访客可以看「我是谁、我会什么、我做过什么、我写了什么」；管理员登录后台后可以直接修改这些内容，不需要改代码。

**三个硬要求**

1. 深色主题 + 星空背景，界面简洁现代。
2. 手机、平板、电脑都能正常浏览。
3. 有后台，能修改个人信息、技能、项目、文章。

## 2. 角色

| 角色 | 能力 |
| --- | --- |
| 访客 | 浏览首页、关于、项目、博客 |
| 管理员 | 登录后增删改个人信息、技能、项目、文章 |

只有一个管理员账号，不开放注册。

## 3. 前台页面

### 3.1 首页 `/`

- Hero：状态标签、姓名、一句话定位、补充说明、两个按钮（看项目 / 读博客）、社交链接。
- 精选项目：2–3 个卡片。
- 最新文章：3 篇。
- 联系区：邮箱 + GitHub。
- 背景：全局星空，首屏可偶发流星。

### 3.2 关于 `/about`

- 头像、简介。
- 技能：按分类分组，显示等级（熟练 / 熟悉 / 了解）和一句说明。
- 联系方式与社交链接。

### 3.3 项目 `/projects`、`/projects/[id]`

- 列表：封面（无图时渐变占位）、标题、摘要、技术标签、外链。
- 详情：简介、技术栈、正文、Demo / 源码链接。

### 3.4 博客 `/blog`、`/blog/[id]`

- 列表：标题、摘要、日期、标签。
- 详情：正文（支持标题、列表、代码块、加粗、链接、行内代码）、标签、返回列表。

### 3.5 其他

- 顶部导航（桌面）/ 底部 4 项导航（手机）。
- 页脚：版权、社交链接。
- 404 页面。

## 4. 后台

登录地址 `/admin/login`，演示账号 `admin / admin123`（可在环境变量修改）。

| 页面 | 功能 |
| --- | --- |
| `/admin` | 概览：项目数、文章数、技能数、快捷入口 |
| `/admin/profile` | 姓名、身份、定位语、补充说明、简介、头像 URL、城市、邮箱、GitHub、个人网站、状态文案 |
| `/admin/skills` | 新增技能、修改名称/分类/等级/说明、删除 |
| `/admin/projects` | 项目列表、新建、编辑、删除、设为精选 |
| `/admin/posts` | 文章列表、新建、编辑、删除 |

**规则**

- 未登录访问后台自动跳到登录页。
- 保存后前台立即生效（无需重启、无需构建）。
- 表单有基础校验：标题、姓名不能为空。
- 删除需要二次确认。
- 不做的：图片上传、富文本编辑器、草稿/发布流、版本历史、多用户、评论、订阅。

## 5. 数据

全部数据保存在项目根目录 `data/db.json`，首次启动自动生成示例数据。

```json
{
  "profile": { "name": "…", "role": "…", "headline": "…", "bio": "…", "email": "…" },
  "skills": [{ "id": "s1", "name": "React", "category": "前端", "level": "熟练", "note": "…" }],
  "projects": [{ "id": "p1", "title": "…", "summary": "…", "tech": ["Next.js"], "featured": true, "content": "…" }],
  "posts": [{ "id": "a1", "title": "…", "excerpt": "…", "tags": ["随笔"], "content": "…", "createdAt": "2026-09-01" }]
}
```

- 读写使用 Node `fs`，写入采用「临时文件 + 重命名」避免文件损坏。
- 项目与文章 URL 使用简短 id（如 `/projects/p1`），避免中文 slug 问题。

## 6. 设计要点

**视觉**

- 深色底 `#05060A`，卡片 `#0B0E16`，描边 `rgba(255,255,255,0.07)`。
- 主色星蓝 `#7AA2FF`，辅助星云紫 `#A78BFA`；强调色只用于按钮、链接、标签。
- 字体：系统中文栈 + Inter；正文 16–17px，行高 1.7。
- 卡片圆角 16px，内容最大宽 1120px，博客正文 720px。

**星空**

- 三层：CSS 径向渐变星云（底）+ Canvas 静态星点 + 少量呼吸闪烁的星点。
- 首页偶发流星；手机上关闭流星、降低星点数量。
- `prefers-reduced-motion` 时全部静止。
- 单个 Canvas，页面不可见时暂停，DPR 上限 2。

**响应式**

- 断点：手机 < 768px、平板 768–1023px、桌面 ≥ 1024px。
- 手机：单列、底部导航、触控区域 ≥ 44px。
- 项目卡片：1 / 2 / 3 列。
- 首页 Hero 使用 `min-height: 100svh`，避免手机地址栏跳动。

**简洁**

- 每屏一个视觉重点，不用满屏霓虹、不做鼠标拖尾、不做滚动劫持。
- 动效只做 hover 和入场淡入，150–500ms，尊重系统「减少动效」。

## 7. 技术方案

| 项 | 选择 |
| --- | --- |
| 框架 | Next.js 15（App Router）+ TypeScript |
| 样式 | 原生 CSS（CSS 变量 + Grid/Flex），不引 UI 框架 |
| 数据 | `data/db.json` + Node `fs` |
| 鉴权 | 密码 + HMAC 签名 Cookie（httpOnly），7 天有效 |
| 部署 | 本地 `npm run dev` / `npm run build && npm start`，无需数据库和云服务 |

## 8. 验收标准

1. `npm install && npm run dev` 后可直接打开首页，看到完整示例内容。
2. 首页、关于、项目、博客在手机和桌面均无布局错乱。
3. 星空正常显示；开启系统「减少动效」后不再闪烁。
4. 登录后台后修改姓名，刷新首页立即变成新名字。
5. 后台能新增一篇带代码块的文章，并出现在博客列表与首页。
6. 删除项目后，列表与首页同步移除，直接访问旧地址返回 404。
7. 未登录访问 `/admin` 跳转登录页；密码错误有提示。
8. 后台在手机宽度下可正常操作（不要求长文编辑体验）。
